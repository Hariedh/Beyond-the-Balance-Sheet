# Source-verification worksheet

Generated by `scripts/make_verification_worksheet.py` from `data/raw/source_verification.csv`.

**How the values were obtained:** the filing text was read through automated extraction of the primary document (NSE iXBRL filing or company PDF). It was NOT opened and checked visually in a PDF viewer. Page numbers are given only where the extracted text showed them; otherwise the statement/section is named.

**Statuses:** verified = within max(1.5 crore, 0.1%); approx = within 1%; unresolved discrepancy = more than 1% (cause not established, value left as loaded); not like-for-like (`unverified` in the CSV) = the filing figure is defined differently from the loaded one; not yet checked = no comparison made. Difference % is (app - filing) / filing. Each row carries the date it was checked.

Totals: 113 comparisons; verified 97, approx 8, unverified 5, discrepancy 3.

**Coverage:** 12 of 26 real company-years have at least one input compared with a filing; 14 are not yet checked. The dataset is therefore NOT fully verified.
